# Blank Pages

A minimal Vue + Vite portfolio milestone page that is GitHub Pages-ready.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## GitHub Pages deployment

1. Push this repo to GitHub.
2. In the repository settings, enable GitHub Pages with the GitHub Actions workflow.
3. The workflow in `.github/workflows/deploy-pages.yml` will publish the built `dist` folder automatically.
